# Политика использования сайта CubikAI

Последнее обновление: 3 июня 2026 г.

## 1. Принятие условий

Используя веб-сайт CubikAI (далее — «Сайт»), вы подтверждаете, что прочитали, поняли и соглашаетесь с условиями настоящей Политики использования. Если вы не согласны с каким-либо из условий, вы должны немедленно прекратить использование Сайта.

## 2. Описание функционала

Сайт CubikAI предоставляет доступ к нескольким моделям искусственного интеллекта. Часть из них доступна публично в интерфейсе, часть — только для внутреннего тестирования или по специальному запросу.

### 2.1. Публичные модели

**CubikAI 1.1.3**  
Одна из самых первых моделей. Идеально подходит для простого общения, не требует больших вычислительных ресурсов. Может ошибаться в сложных темах.

**CubikAI 1.4-Coder**  
Специализированная модель для задач, связанных с программированием, отладкой кода, объяснением алгоритмов. Показывает высокие результаты в IT-сфере.

**CubikAI 1.7**  
Высокопроизводительная модель для повседневных задач. Оптимизирована для скорости ответа и решения типовых запросов.

**CubikAI 2.0-Think**  
Языковая модель с функцией «раздумия». По некоторым категориям задач превосходит более новые версии. Требует больше времени на генерацию ответа.

**CubikAI 2.6-Ultra**  
Последняя крупная языковая модель на текущий момент. Отличается высокой точностью и качеством при решении сложных, многошаговых и творческих задач.

**CubikAI 1.3-Dark**  
Экспериментальная модель. Склонна выходить за рамки обычных ограничений, давать провокационные, неожиданные или нефильтрованные ответы.

> ВАЖНО: Модель 1.3-Dark может генерировать контент, который некоторые пользователи сочтут неуместным, оскорбительным или провокационным. Использование этой модели осуществляется исключительно на ваш страх и риск. Разработчик не рекомендует использовать данную модель несовершеннолетним и лицам с неустойчивой психикой.

### 2.2. Непубличные / тестовые модели

Помимо перечисленных выше, существуют модели, которые не представлены в открытом интерфейсе, но могут использоваться для внутренних экспериментов или предоставляться по специальному запросу:

- CubikAI 1.9 — тестовая модель, пытающаяся найти баланс между скоростью и глубиной ответа.
- CubikAI 2.1 — отличная версия но с большими требованиями. Также имеет Think версию.
- CubikAI 2.5-Max — предварительная версия перед релизом 2.6-Ultra, содержит ранние улучшения в рассуждениях и отличается «человечностью».
- CubikAI 3.0 — прототип следующего поколения с принципиально новой архитектурой. Доступен только ограниченному кругу тестировщиков.

Если вы заинтересованы в доступе к какой-либо из непубличных моделей, обратитесь к разработчику через контакты в разделе 10.

### 2.3. Общие ограничения

Все ответы генерируются искусственным интеллектом, который находится в стадии активного развития. Модели могут допускать фактические ошибки, логические нестыковки, «галлюцинации» (выдумки) или устаревшую информацию. Не принимайте критически важные решения, основываясь исключительно на ответах CubikAI.

## 3. Сбор и использование данных

3.1. Какие данные собираются:
- История диалогов: все текстовые сообщения, отправленные через интерфейс сайта, хранятся в локальном хранилище вашего браузера (localStorage) и могут передаваться на сервер для обработки.
- Технические данные: при отправке запросов на VPS-сервер передаются: текст сообщения, выбранная модель, идентификатор чата и API-ключ для аутентификации.
- Анонимная статистика использования (количество чатов, выбранные модели) может собираться для улучшения работы сервиса.

3.2. Как НЕ используются данные:
Мы не передаём содержимое ваших диалогов третьим лицам без явного требования закона. Данные используются исключительно для генерации ответов ИИ и улучшения качества работы моделей.

3.3. Локальное хранение:
Ваши чаты сохраняются в localStorage вашего браузера. Очистка кэша браузера может привести к безвозвратной потере истории диалогов. Разработчик не несёт ответственности за утрату данных по этой причине.

## 4. Ограничение количества чатов

На одном устройстве одновременно может существовать не более 10 чатов. При попытке создать 11-й чат система отобразит уведомление о достижении лимита. Для создания нового чата необходимо удалить один из существующих.

## 5. Жалобы на контент и перегенерация

5.1. Рядом с каждым ответом бота присутствуют кнопки:
- C (Копировать) — копирование текста ответа в буфер обмена.
- R (Перегенерировать) — повторная генерация ответа на тот же запрос.
- S (Пожаловаться) — отправка уведомления разработчику о проблемном контенте.

5.2. При нажатии «S» вы помогаете улучшить модели CubikAI. Мы рекомендуем сообщать о любых опасных, незаконных или неуместных ответах, особенно полученных от модели 1.3-Dark.

## 6. Возрастные ограничения

Обычные модели (1.1.3, 1.4-Coder, 1.7, 2.0-Think, 2.6-Ultra) рекомендуется использовать с 12 лет под контролем родителей.

Модель 1.3-Dark НЕ рекомендуется для лиц младше 18 лет, а также для людей с психическими расстройствами, склонностью к тревожности или депрессивным состояниям. Использование данной модели происходит на собственный риск пользователя.

Тестовые и непубличные модели предназначены для совершеннолетних опытных пользователей, понимающих риски работы с нестабильным ПО.

## 9. Публичный API

CubikAI предоставляет открытый программный интерфейс (API) для разработчиков, желающих интегрировать возможности моделей в свои приложения, ботов или сервисы.

### 9.1. Доступ к API

API находится по адресу: `http://80.66.72.139:8080/api/cubik`

Для использования API требуется API-ключ. Публичный ключ для тестирования и некоммерческого использования:  
`CUBIK54J2VV3884RI7YOF1KQME71RC98ZLO`
В будущем будет возможность создать свои API ключи.

### 9.2. Формат запроса

Отправляйте POST-запрос с содержимым `application/json`:

{
  "message": "текст запроса",
  "model": "fast|think|master|custom|coder|mini", # "denoglu" для ИИ без конфига
  "custom": true|false,
  "chat_id": "уникальный идентификатор чата",
  "api_key": "ваш API-ключ"
}

Параметр chat_id используется для отслеживания контекста диалога, но не обязателен при каждом запросе.

### 9.3. Пример ответа json

{
  "reply": "сгенерированный ответ модели",
  "model_used": "fast"
}

### 9.4. Ограничения и условия

· Публичный ключ предназначен для ознакомления и небольших проектов. При высокой нагрузке (более 20 запросов в минуту) сервер может ограничить доступ к ключу по количествам запросов в неделю (до 30).
· Мы оставляем за собой право блокировать ключи и добавлять ваш IP в чёрный список Cubik. Если вы нарушаете политику или злоупотребляете API.
· API предоставляется «как есть». Мы не гарантируем время ответа или круглосуточную доступность.
· Для коммерческого использования или высоких нагрузок запросите отдельный ключ у разработчика (см. контакты в разделе 10).

### 9.5. Документация
