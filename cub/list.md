# Список моделей CubikAI (История)

## Публично доступные модели на сайте

### CubikAI 1.1.3
Одна из самых первых моделей. Идеально для простого общения. Не требует много ресурсов, может ошибаться в сложных темах.
Идентификатор: mini

### CubikAI 1.4-Coder
Специализированная модель для задач, связанных с программированием и IT. Хорошо объясняет код, помогает отлаживать, пишет сниппеты.
Идентификатор: coder

### CubikAI 1.7
Высокопроизводительная модель для повседневных задач. Оптимизирована для скорости ответа. Считается лучшей среди остальных.
Идентификатор: fast

### CubikAI 2.0-Think
Модель с функцией внутреннего раздумия. Дольше генерирует ответ, но лучше справляется с логическими задачами.
Идентификатор: think

### CubikAI 2.6-Ultra
Крупнейшая актуальная модель. Высокая точность, глубокое понимание контекста. Рекомендуется для сложных, многошаговых задач.
Идентификатор: master

### CubikAI 1.3-Dark
Экспериментальная модель без обычных фильтров. Может давать провокационные и неожиданные ответы. Используйте на свой страх и риск.
Идентификатор: custom

## Дополнительная модель для использования в API

### AI-Clear
Модель без настроек и конфигурации (пустая), идеальна для использования в API. Работает на архитектуре CubikAI 1.7
Идентификатор: denoglu или clearai

## Потерянные / приватные модели

Следующие модели не отображаются в стандартном интерфейсе, но могут быть доступны по специальному запросу у разработчика (см. раздел «Контакты» в политике). Они используются для внутреннего тестирования или закрытого бета-тестирования.

### CubikAI 1.2 и ниже (Потерян)
Самые первые модели. Плохая скорость и архитектура памяти, менее 2B параметров.
Сюда входят: CubikAI ; CubikAI-Think ; CubikAI-1.0 ; CubikAI 1.1 ; CubikAI 1.2

### CubikAI 1.5 и 1.6 (Не существовали)
Не существовали вовсе

### CubikAI 1.8-Think (Потерян)
Высокопроизводительная модель с внутренним раздумием. Первая модель с отлично воссозданной работой Think.

### CubikAI 1.9
Предрелизная версия перед 2.0. Содержит ранние улучшения в рассуждениях, но очень нестабильная.

### CubikAI 2.1 и 2.1-Think
Высокопроизводительная модель, но с высокими системными требованиями.

### CubikAI 2.5-Max
Одна из самых мощных моделей Cubik. Была заменена Cubik 2.6 и 2.6-Ultra по соотношению требование-качество

### CubikAI 3.0 (Не распространяется)
Не законченный прототип следующего поколения с новой архитектурой. Не распространяется. Возможны кардинальные изменения в поведении.

### Cubik Vision (Потерян)
API для анализирования изображений и коротких видео. Комбинируется с CubikAI версии от 2.0

### CubikAI 33B (Потерян)
Сверхбольшая модель (33 миллиарда параметров) для сложных программных проектов. Не выложена в открытый доступ из-за высоких системных требований. Была похоронена вместе с версиями 1.2 и ниже на мёртвом SSD

## Как выбрать модель в интерфейсе?

Нажмите на кнопку с названием текущей модели (например, «CubikAI 1.7») в верхней панели. Появится выпадающий список со всеми публичными моделями. Выберите нужную — новый чат будет использовать её по умолчанию. Уже созданные чаты сохраняют выбранную модель навсегда (до смены пользователем вручную).

Примечание: Если вы хотите протестировать непубличную модель, напишите @AuriX_help в Telegram с темой «Модель»
