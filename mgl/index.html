01 Возможности

Всё, что нужно для игры.
И ничего лишнего.

Браузер контента

Моды, текстуры, шейдеры и модпаки с Modrinth прямо в лаунчере. Фильтр по версии и загрузчику, установка одной кнопкой в нужную папку.

  • Моды → .minecraft/mods
  • Ресурспаки → .minecraft/resourcepacks
  • Включай и выключай моды, не удаляя их

Библиотека сборок

Каждая сборка получает свою абстрактную иконку. Закрепляй любимые, переименовывай, запускай в один клик. Рядом список активных сессий с PID и временем игры.

  • Release, snapshot, beta и alpha
  • Forge, Fabric, NeoForge, Quilt
  • Остановка игры прямо из лаунчера

Скины и плащи

Менеджер скинов с 3D-превью. Загрузи PNG, выбери плащ и нажми «Применить». Системные моды MGL Skin Core покажут его в игре на Forge 1.8.9 / 1.12.2 и Fabric 1.16.5 / 1.20.1.

  • Свои плащи и коллекция скинов
  • Аккаунт MGL, Microsoft или офлайн

Свой сервер в два клика

Создай сервер прямо из лаунчера, запусти его и управляй через встроенную консоль: op, say, whitelist с историей команд. Добавленные серверы показывают пинг, онлайн и MOTD.

  • Память, порт и версия на каждый сервер
  • Перезапуск, логи, папка в одном ряду
  • Серверы попадают в список в игре

Фон, который выбираешь ты.

03 Под капотом

Для тех, кто любит
покрутить ручки.

  • Java самаСтавит Mojang Runtime: Java 8, 17 или 21. Нужная подбирается к версии игры.
  • Память ползункомВыделяй RAM без ручного -Xmx, а свои JVM-аргументы допиши ниже.
  • Хуки запускаPre-launch, wrapper и post-exit команды с переменными %INST_NAME% и другими.
  • Quick PlayСразу после запуска заходит на сервер, в мир или Realms.
  • Фильтр версийПоказывай только релизы или открой снапшоты, беты и альфы.
  • Своя .minecraftСмени папку игры и перенеси всё содержимое одной кнопкой.
  • Своя панельПорядок и видимость иконок слева, растягивающиеся пробелы.
  • Режим оптимизацииБез неона, анимаций и фона, с экономией трафика. Включается одним переключателем.
  • СтатистикаВремя в игре, число запусков, любимая версия, сборка и модлоадер.

Плагины на JavaScript

Лаунчер написан на Electron, и плагин получает доступ ко всему коду: интерфейсу, запуску игры, файлам и сети. Новая вкладка, своя тема, интеграция с Discord или мини-игра в меню — пиши что захочешь.

  • Обычный JS: Node.js и Electron API под рукой
  • Меняй интерфейс и встраивайся в запуск игры
  • Без песочницы и урезанных API
plugins/hello/index.js · пример
// плагин — это обычный JS-модуль
module.exports = {
  name: 'hello',
  activate({ ui, game }) {
    ui.addTab({ title: 'Змейка' });
    game.on('launch', v =>
      console.log(`Запуск ${v.id}`));
  }
};
